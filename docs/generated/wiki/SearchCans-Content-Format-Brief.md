# SearchCans Content Format Brief

> A localized inventory of Google web, images, videos, and short-video result formats

## Best for

Editorial format discovery, visual/video search research, and SEO/GEO content format planning.

## SearchCans APIs used

- Google Search
- Google Images
- Google Videos
- Google Short Videos
- Account

## Account-aware behavior

Checks one pre-flight per requested format and caps the selected formats in a fixed priority order.

## Use it

```text
Use $searchcans-content-format-brief to map localized content formats for this topic.
```

Read the executable [SKILL.md](https://github.com/SearchCans/searchcans-skills/tree/main/skills/searchcans-content-format-brief) for supported flags, evidence boundaries, and report guidance.

## Interpretation boundary

Map localized Google web, image, video, and short-video result formats into a bounded content-format brief. Use for SEO/GEO content planning, editorial format discovery, visual-search research, and deciding which formats need further page-level validation.
